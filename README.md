# Сербское лето / Serbian Summer

Браузерная романтическая визуальная новелла о переезде в Сербию. Основная платформа — iPhone в вертикальном положении, Safari и PWA. Русский и английский языки, пролог и шесть глав. Текущая версия: **0.13.1**.

[Открыть игру](https://serbskoe-leto.peregon.chatgpt.site/)

## Начало работы для Codex и Claude Code

Сначала прочитайте [PROJECT.md](PROJECT.md): общий контекст, персонажи, карта кода, правила совместимости и совместной работы. [AGENTS.md](AGENTS.md) и [CLAUDE.md](CLAUDE.md) ведут к одной общей инструкции.

Команды из корня этого репозитория, Node.js >=22.13.0:

```sh
npm run install:ci
node --test tests/*.test.mjs
npm run dev -- --port 4174 --hostname 127.0.0.1
```

Проверка сборки: `npm run build`. Код фронтенда находится в `public/`, API — в `app/api/` и `lib/`. Рабочие изображения, музыка и шрифты включены в `public/assets/`. База данных игроков, секреты, локальные сохранения и PNG-мастеры в этот репозиторий не входят.

Это исходники существующей игры: не создавайте новый проект вместо него. Публикация пока выполняется через Sites отдельно от GitHub; push сам по себе не обновляет публичную игру. Для каждой следующей задачи создавайте отдельную ветку и pull request.

# Русский и английский 0.11.0

В главном меню доступен переключатель RU / EN. При первом запуске русский выбирается для основного языка устройства ru, английский — для остальных. Ручной выбор хранится отдельно в ss-language и имеет приоритет при следующих запусках. Переключение не меняет сюжет, сохранение, ответы, отношения и точки возврата.

Перевод всех 124 сцен, вариантов, дневника, названий глав и интерфейса хранится в public/locales/en.json. Русские исходники остаются каноническими: новая история реплик записывается по-русски и переводится при показе. Имена в английском варианте передаются латиницей; идентификаторы имён не меняются. Для установки с английским названием предусмотрен manifest.en.webmanifest.

Проверка tests/localization.test.mjs требует перевод для каждой строки данных сюжета и проверяет обе версии героя, все 24 имени, динамические имена хозяев, историю реплик, выбор по устройству и сохранение исходных данных. Английские строки перед публикацией прошли браузерную проверку на 320 × 568, включая создание персонажа, багаж, варианты, карту, вход и настройки.

# Мобильный интерфейс и интерактивные сцены 0.10.1

На стартовом экране версия показана рядом с иконками глав, прогресса и настроек. В игре версия скрыта. Заголовок учитывает безопасную область iPhone, включая минимальный запас для standalone при env=0; постер заполняет фон без верхнего сдвига. Цвет html/body согласован с экраном до запуска JS, в том числе при тёмной теме. Области, которые сама iOS размещает вне веб-окна, остаются ограничением системы.

Категории ответов представлены компактными SVG: бинокль, сердце, друзья, книга, искра. Розовый и синий указывают адресата; доступные названия сохраняют категорию и имя. Персонажи получили разные цвета имени.

Обычные tap-переходы выполняются одной кнопкой «Дальше» с сохранением прежних эффектов и возврата назад; дубли в иллюстрации и под текстом удалены. Багаж вынесен в отдельный экран: фотография заполняет фон, нажатие на чемодан завершает исходное действие. Геометрия hit area учитывает cover-кадрирование. Сидящая Милица имеет четыре кадра с керамической чашкой; открытый рисунок показан отдельной вставкой.

# PWA и навигация 0.9.1

Меню главного экрана теперь снизу. В игре история, дневник, главы и настройки находятся в отдельной нижней панели. На верхнем краю рисунка нет текста. Фон главного экрана без CSS-размытия. Стиль адаптации — `public/viewport.css`, загружается после темы. Режим/цвет краёв обновляется при смене экрана.

Локальная диагностика: Настройки → «Сведения об экране · 0.9.1». Геометрия остаётся на устройстве. Страница не предполагает, что вся screen.height доступна для размещения кнопок: системные особенности конкретной iOS PWA требуют проверки на устройстве.

# Главы и продолжение 0.9

Пролог «Жара на посадке», глава 1 «Своя дверь», глава 2 «Район для жизни», глава 3 «Счёт на себя». Всего 120 доступных сцен и 21 фон. Новые 19 сцен: решение после просмотра, вопросы к договору, подготовка к банковской консультации, выбор рабочего направления и новая встреча с Николой или Милицей. В конце — план следующего дня. Решение остаться в Сербии или уехать по-прежнему остаётся за игроком в будущем сюжете.

«Главы» доступны на главном экране, внизу игровой сцены и после завершения. Главы открываются последовательно. При входе сохраняется точка с прежними выборами, журналом и отношениями. Переигрывание просит подтверждение, сохраняет предысторию и убирает последующие ветки. Можно предварительно скачать всю текущую историю. Точки глав синхронизируются с аккаунтом и входят в экспорт. Старая версия сохранения поддерживается: для старого файла точка текущей главы создаётся на текущей реплике; старые промежуточные состояния нельзя восстановить задним числом. В прежнем конце доступно продолжение новой главы.

PWA: вычисляемая высота видимого окна, повторный расчёт при возвращении/изменении размера, безопасная зона над надписями и меню. Кнопка глав перенесена в нижнюю панель с достаточной областью касания. Сама иллюстрация заполняет сцену. В длинных выборах остаётся естественная прокрутка.

Дополнительная проверка: `node tests/chapters.test.mjs`. Сюжет и меню: `public/chapter-three.js`, `public/chapters.js`. Сохранения: дополнительное необязательное поле `chapterMarks`, без изменения storyVersion и без миграции базы.

# Сербское лето — игровой прототип

Браузерная новелла с необязательным внутренним логином и паролем и облачным прогрессом. Игровой фронтенд — `public/`; API и аккаунты — Vinext + Cloudflare D1. `dist/` генерируется сборкой.

## Запуск

Из папки `game`:

```sh
npm run dev -- --port 4174 --hostname 127.0.0.1
```

Открыть напечатанный сервером локальный URL. Локальная и опубликованная версии используют собственные аккаунты D1. Для iPhone используется опубликованная HTTPS-версия; localhost другого компьютера с телефона не открывается.

- Выбор пола, 12 готовых имён для каждого пола, полная и дружеская формы.
- Общий прилёт и две стартовые ветки: Милица у кофе и Никола в «Хлеб & Кифле».

- Ориентир — около 10–15 минут с выбором и чтением; реальный пользовательский тайминг ещё предстоит измерить.
- Девять пользовательских фонов распределены по этапам прибытия; восемь аккуратно перерисованы для повышения чёткости, кадр такси создан заново. Высокие мастеры и исходники — в `../artwork/airport/`.
- Девять эмоций Николы. В обычных сценах сохраняется рабочая форма, три воображаемых варианта открываются только в короткой необязательной фантазии после флирта.
- Возврат до двух шагов назад, в том числе отмена ответа вместе с его последствиями.
- Локальное автосохранение: IndexedDB с синхронной резервной копией в localStorage.
- История реплик, дневник, настройка размера текста. Оригинальная инструментальная тема 1:42 с повтором, кнопкой звука и громкостью.
- Полная ширина на телефоне, динамическая высота, безопасные отступы iPhone. Установка на домашний экран для запуска без панелей Safari.
- Минимальный главный экран с плотными шрифтами и приглушённым фоном. Выбор «С музыкой» / «Без музыки» после начала игры; дальнейшее управление звуком — в настройках.
- Экспорт и импорт сохранения для переноса между браузерами.

## Файлы

- `public/story.js` — сценарные узлы, реплики, переходы и дневник.
- `public/app.js` — экран создания персонажа и проигрыватель.
- `public/storage.js` — локальное сохранение и чтение.
- `public/audio.js` — воспроизведение локального AAC-трека после касания, Web Audio для громкости, пауза при уходе в фон.
- `public/assets/prologue-theme.m4a` — оригинальная синтезированная музыка без сторонних сэмплов; исходник композиции — `../artwork/music/compose_prologue.py`.
- `public/manifest.webmanifest` — запуск с домашнего экрана в отдельном окне.
- `public/names.json` — копия авторского каталога из `../data/player-names.ru.json`.
- `public/assets/` — сжатые иллюстрации и локальные шрифты с лицензиями.
- `.openai/hosting.json` — идентификатор и конфигурация размещения; повторно создавать Site не нужно.

Для первого теста выбран небольшой собственный граф сцен на JavaScript без стороннего runtime. Переход на TypeScript и Ink из производственного плана остаётся решением следующего этапа; текущая сборка не требует их установки.

Формат сохранения и сценария — версия 1. Профиль, положение, выборы и дневник проверяются при импорте. Гостевой прогресс хранится в браузере; после необязательного входа доступна облачная синхронизация.

На iPhone: Safari → «Поделиться» → «На экран Домой» → оставить «Открывать как веб-приложение», если переключатель доступен. В обычной вкладке сайт не может принудительно убрать системные панели Safari. При раздельном хранилище веб-приложения прогресс переносится экспортом и импортом.

## Аккаунт и облако

Гостевой режим сохраняется. «Мой прогресс» позволяет зарегистрировать внутренний логин и пароль без ChatGPT. Секретный код восстановления показывается один раз: его нужно сохранить самостоятельно. После восстановления выдаётся новый код и завершаются прежние сессии. Email и рассылки не используются.

После входа локальная история переносится в аккаунт; при разных историях игрок выбирает нужную. Облако хранит персонажа, сцену, журнал, ответы и два шага возврата. Настройки звука, текста и темы остаются на устройстве. При существующем старом входе доступен добровольный перенос прежнего облачного сохранения в новый аккаунт, без удаления оригинала.

Пароли хранятся как scrypt-хеши с отдельной случайной солью. Случайные сессии передаются в HttpOnly Secure SameSite cookie; в базе только хеш токена. Есть ограничение попыток и проверка Origin. Подробности — `AUTH.md`.

Сборка: официальный `build-site.mjs` плагина Sites. Hosting manifest сохраняет project ID; D1 binding — `DB`, миграции в `drizzle/`. Локальная база отдельна от production. Публикация применяет новые миграции, тестовые строки не публикуются.

Проверки: `node tests/story.test.mjs`, `node tests/rewind.test.mjs`, `node tests/progress-api.test.mjs`, `node tests/accounts.test.mjs`, `node tests/mobile-pacing.test.mjs`.
