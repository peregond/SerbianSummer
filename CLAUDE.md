# Claude Code project entry point

Read PROJECT.md, AGENTS.md, and docs/PUBLISHING.md first. Use the same shared instructions as Codex; do not maintain a divergent copy of the product rules here.

For an onboarding request, inspect the existing project, report its architecture and test/build results, then wait for the requested task selection. Do not create a replacement application.

When asked to release, update GitHub main through a reviewed branch, then publish that exact source through the existing Sites project. A GitHub push alone is not a deployment. If this Claude environment has no authenticated Sites tools, finish the GitHub work and clearly hand off the verified commit for publication; never claim that the public site changed.
