# Визуальная библиотека

Текущий набор: **70 постановочных фонов и 117 зарегистрированных портретов**. Для 11 героев и трёх дополнительных повседневных/служебных образов подготовлено по **восемь обычных эмоций**: приветливость, задумчивость, смех, флирт, смущение, удивление, уверенность и беспокойство. Пять специальных фантазий Николы учитываются отдельно.

Новая партия — 26 прозрачных портретов и 14 вертикальных фонов. У Милоша завершены наборы в балаклаве и защитной экипировке и в летней форме без балаклавы. Беспокойство добавлено каждому герою, включая Николу после смены. Служебные образы сохраняют одежду и скрытое лицо до раскрытия; дружеский ответ не включает флирт.

Новые фоны закрывают ночную и утреннюю комнату, дневную кухню, дом Аси вечером, кафе в сумерках, двор после кино, районную булочную, подготовку переводов, страховки и бюджета, зал вылета, дождь за окном и два вида из самолёта. Они назначены существующим сценам или отдельным кадрам, согласно тексту. Например, встреча после выбора страховки возвращается на набережную, а последний кадр отъезда показывает полёт, а не аэропортовый перрон. Поле времени последнего ночного кадра отображает «Позже».

## Где искать

- `public/living-art.js` — исходные обычные наборы и первая партия новых локаций.
- `public/abundant-art.js` — новая партия, назначения фонов по сценам/страницам и дополнительные портреты в очных сценах.
- `public/assets/` — игровые WebP. Старые изображения и эскизы сохранены.
- `artwork/visual-abundance/PROMPTS.json` — 40 промптов, референсы и пути PNG-мастеров. Оригинальные генерации сохраняются вне веб-пакета в `/workspace/generated_images/`.
- `artwork/visual-audit.json` — воспроизводимый отчёт по файлам, эмоциям и образам.

В настройках через промокод `грызуны` открывается мастерская. Фильтр «Образ персонажа» позволяет отдельно смотреть форму, балаклаву, основной образ и другие варианты. «Чего не хватает» показывает наличие и регистрацию всех восьми эмоций для каждого обычного образа. Постановочные сцены, фантазии и архивные версии не скрывают недостающие обычные реакции. Зарегистрированные портреты составляют доступную движку библиотеку; фактически встречающиеся в сценах файлы посчитаны отдельно в `stagedPortraits` отчёта.

## Проверка и обновление отчёта

```sh
node scripts/generate-art-catalog.mjs
node scripts/audit-visuals.mjs --write
node --test tests/*.test.mjs
npm run lint
npm run build
```

Аудит проверяет файлы, все обычные образы и постановку для сочетаний собеседника, владельца жилья, района, сотрудников и развязки Милоша. Отсутствующий файл, неизвестная реакция, неполный набор образа или неиспользуемый зарегистрированный фон дают ненулевой код завершения.

ID сцен, последовательность и тексты страниц, выборы, эффекты и формат сохранения не изменены. Проверка совместимости сравнивает семантику всех 445 сцен с исходным снимком `90fe350`, исключая фон, эмоциональную постановку и шесть согласованных уточнений собеседника «Мама» (tests/fixtures/mother-edits.json).
